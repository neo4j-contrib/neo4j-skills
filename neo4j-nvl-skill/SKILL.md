# Neo4j Visualization Library (@neo4j-nvl/base)

> Shipped with `@neo4j-nvl/base` v2.1.0. Once installed into a project this folder is detached from the
> package: the installed types in `node_modules/@neo4j-nvl/*` are the source of truth. If the project's
> `@neo4j-nvl/base` is a different version and `node_modules/@neo4j-nvl/base/skills/neo4j-nvl-skill/SKILL.md`
> exists, read that copy instead.

## When to use

- Rendering a Neo4j graph in the browser with custom interactions, rendering or data shapes
- Visualizing `driver.executeQuery` results as an interactive graph
- Zoom, pan, drag, click, hover, lasso or box-select interactions; clustering; custom layouts

Not for: a pre-styled graph view with default behaviour (`GraphVisualization` from `@neo4j-ndl/react` wraps
NVL for that), Python notebooks (`neo4j/python-graph-visualization`), Cypher, driver setup, GDS or GraphQL.

## Before you code

1. The container has explicit `width` **and** `height`; otherwise the graph is invisible.
2. React wrappers: `layout`, `layoutOptions` and every other option go inside `nvlOptions`.
3. Wheel zoom in `<InteractiveNvlWrapper>` is enabled by `mouseEventCallbacks.onZoomAndPan`; there is no `onZoom`.
4. `fit()` needs explicit node ids. `fit([])` fits nothing.
5. The WebGL renderer draws no captions. Use `'canvas'` when labels matter, or `html` / `icon` overlays.
6. If the hierarchical layout never finishes under the Vite dev server, add `optimizeDeps: { include: ['bin-pack'] }`. Vite 7.3 pre-bundles it on its own, so only apply it when the symptom appears.
7. `nvlResultTransformer` returns bare `{ id }` elements; labels and properties are in `recordObjectMap`.
8. React: `nvlCallbacks` are captured once; use refs or stable functions. `interactionOptions` replaces
   the defaults, so pass every option you need.
9. Destroy interaction handlers, then `nvl.destroy()`, on teardown. The React wrappers do this for you.
10. `updateCallback(name, cb)` on interaction handlers is untyped: `cb` is `(...args: unknown[]) => void`, so
    parameters arrive as `unknown` and a typed callback such as `(node: Node) => …` fails under `strict`. Cast
    inside the callback; the React `mouseEventCallbacks` are fully typed.

## Symptom → cause → fix

| Symptom | Cause | Fix |
|---|---|---|
| Graph invisible / blank | Container has no height | Explicit `width` and `height` on the container |
| Wheel does not zoom (React) | Zoom handler only wired from `onZoomAndPan` | `mouseEventCallbacks={{ onZoomAndPan: true }}` → [react-wrappers](references/react-wrappers.md) |
| Hierarchical layout never finishes (Vite dev) | Layout `SharedWorker` imports CJS `bin-pack`; seen on older Vite, not on 7.3 | `optimizeDeps: { include: ['bin-pack'] }` → [vite-and-bundlers](references/vite-and-bundlers.md) |
| No text on nodes with WebGL | Captions are Canvas-only | `html` / `icon`, own overlay, or `setRenderer('canvas')` → [labels-and-overlays](references/labels-and-overlays.md) |
| `fit([])` does nothing | Empty array = no nodes | `fit(nvl.getNodes().map((n) => n.id))` |
| `fit()` stops zoomed in on a huge graph | `minZoom` clamp (default `0.075`) | `fit(ids, { minZoom })` or lower the `minZoom` option |
| Clicking a cluster selects all its nodes | `selectOnClick` selects `cluster.nodeIds` | `selectOnClick: false` and select in `onNodeClick` → [clustering](references/clustering.md) |
| No cluster outlines / halos | Not force-directed, or mixed colours (halo) | Force-directed with `layoutOptions.clustering`; one colour per cluster → [clustering](references/clustering.md) |
| Pinned nodes move when clustering is on | Cluster forces ignore pins | Do not combine → [clustering](references/clustering.md) |
| Changing circle options does nothing | Layout is not re-run on option change | Bounce via `setLayout('free')` → [layouts-and-positions](references/layouts-and-positions.md) |
| Un-pinned nodes stay frozen | Settled simulation is not restarted | `setNodePositions(current, true)` → [layouts-and-positions](references/layouts-and-positions.md) |
| Node `x`/`y` are ignored | Positions are owned by the layout; never set `x`/`y` on node data | `setNodePositions(nodes)` or the React `positions` prop → [layouts-and-positions](references/layouts-and-positions.md) |
| Callbacks see stale state (React) | `nvlCallbacks` captured at creation | Refs or stable functions → [react-wrappers](references/react-wrappers.md) |
| Minimap empty (React) | Container did not exist at creation | Keep the element in state → [react-wrappers](references/react-wrappers.md) |
| Hover / shadow defaults lost | `interactionOptions` replaces defaults | Pass every option → [react-wrappers](references/react-wrappers.md) |
| Many icons not drawn (WebGL) | More than 256 distinct icon images | Fewer distinct icons, or `'canvas'` → [labels-and-overlays](references/labels-and-overlays.md) |
| Layout looks hung in headless Chrome | Software WebGL | Hardware-GL flags → [verifying-nvl-apps](references/verifying-nvl-apps.md) |
| Raw `executeQuery` result passed to NVL | Records are not graph elements | `resultTransformer: nvlResultTransformer` → [data-from-neo4j](references/data-from-neo4j.md) |

## Choose

**NVL or Needle?** Default Neo4j styling and no custom interaction → `GraphVisualization` from `@neo4j-ndl/react`.
Anything custom → NVL.

| Need | Use |
|---|---|
| React, default interactions | `<InteractiveNvlWrapper>` from `@neo4j-nvl/react` |
| React, custom interaction logic | `<BasicNvlWrapper>` + `ref` to the `NVL` instance |
| Vanilla, standard interactions | `NVL` + `@neo4j-nvl/interaction-handlers` |
| Vanilla, custom events | `NVL` + `container.addEventListener` + `nvl.getHits()` |
| Static PNG / SVG | `<StaticPictureWrapper>` or `nvl.saveToFile()` / `nvl.saveToSvg()` |

| Renderer | Nodes | Notes |
|---|---|---|
| `'canvas'` (default) | up to ~1,000 | Captions, icons, arrows, exact hit-testing |
| `'webgl'` | 100,000+ | WebGL2 only; no captions; icons and arrowheads supported |

`disableWebGL: true` forces Canvas rendering and non-GPU layouts.

## Minimal examples

```javascript
import { NVL } from '@neo4j-nvl/base'
import { ClickInteraction, ZoomInteraction, PanInteraction, DragNodeInteraction } from '@neo4j-nvl/interaction-handlers'

const nodes = [{ id: '1', caption: 'A' }, { id: '2', caption: 'B' }]
const rels = [{ id: '12', from: '1', to: '2', type: 'KNOWS' }]
const nvl = new NVL(container, nodes, rels, { layout: 'forceDirected' }, {
  onLayoutDone: () => nvl.fit(nodes.map((n) => n.id))
})
const click = new ClickInteraction(nvl, { selectOnClick: true })
click.updateCallback('onNodeClick', (node) => console.log('clicked', node))
const handlers = [click, new ZoomInteraction(nvl), new PanInteraction(nvl), new DragNodeInteraction(nvl)]
// teardown: handlers.forEach((h) => h.destroy()); nvl.destroy()
```

```tsx
import { InteractiveNvlWrapper } from '@neo4j-nvl/react'
import type { NVL } from '@neo4j-nvl/base'
import { useRef } from 'react'

export function Graph({ nodes, rels }) {
  const nvlRef = useRef<NVL>(null)
  return (
    <div style={{ width: '100%', height: 600 }}>
      <InteractiveNvlWrapper
        ref={nvlRef}
        nodes={nodes}
        rels={rels}
        nvlOptions={{ layout: 'forceDirected', renderer: 'canvas' }}
        interactionOptions={{ selectOnClick: true, drawShadowOnHover: true }}
        mouseEventCallbacks={{
          onNodeClick: (node) => console.log(node.id),
          onZoomAndPan: true,
          onPan: true,
          onDrag: true
        }}
        nvlCallbacks={{ onLayoutDone: () => nvlRef.current?.fit(nodes.map((n) => n.id)) }}
      />
    </div>
  )
}
```
