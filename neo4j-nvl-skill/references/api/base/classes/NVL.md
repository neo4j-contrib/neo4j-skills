# Class: NVL

Class for a NVL instance.

## Example

This is a basic setup for a NVL instance.
```ts
import { NVL } from '@neo4j-nvl/base'

const nodes = [{ id: '1' }, { id: '2' }]
const relationships = [{ id: '12', from: '1', to: '2' }]

const options = { initialZoom: 0.5 }

const callbacks = {
  onLayoutDone: () => console.log('Layout done')
}

const nvl = new NVL(document.getElementById('frame'), nodes, relationships, options, callbacks)
```

### getHits()

```ts
getHits(
   evt, 
   targets?, 
   hitOptions?
): NvlMouseEvent;
```

Gets the nodes, relationships, and clusters that have been hit by a pointer event.

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `evt` | `MouseEvent` | The mouse event. |
| `targets` | [`HitTestTarget`](../type-aliases/HitTestTarget.md)[] | The graph elements to check for hits. Defaults to ['node', 'relationship', 'cluster']. |
| `hitOptions` | \{ `hitNodeMarginWidth`: `number`; \} | Options for the hit test. `hitNodeMarginWidth` widens the node hit area in layout units. |
| `hitOptions.hitNodeMarginWidth` | `number` | - |

#### Returns

[`NvlMouseEvent`](../interfaces/NvlMouseEvent.md)

A [NvlMouseEvent](../interfaces/NvlMouseEvent.md) with the [HitTargets](../type-aliases/HitTargets.md) property
containing the nodes, relationships, and clusters that have been hit by the pointer event.

#### Remarks

Clusters are hit when the pointer is inside a cluster hull, including over its nodes.
This is the way to react to cluster hover; the hover interaction handler only reports nodes and relationships.

#### Example

```ts
import { NVL } from '@neo4j-nvl/base'

const container = document.createElement('div')
const nvl = new NVL(container, [{ id: '0' }], [])

// Get the nodes and relationships that have been hit by a pointer event.
container.addEventListener('click', (evt) => {
  const { nvlTargets } = nvl.getHits(evt)
  console.log('clicked elements:', nvlTargets)
})

// Cluster hover
container.addEventListener('mousemove', (evt) => {
  const cluster = nvl.getHits(evt, ['cluster']).nvlTargets.clusters[0]?.data
  console.log('hovered cluster:', cluster?.id)
})
```
