# Type Alias: NodeWithClientPosition

```ts
type NodeWithClientPosition = Node & Point & {
  clientPosition: Point;
};
```

A node returned by [NVL.getNodes](../classes/NVL.md#getnodes) with layout coordinates and screen position.
`x` and `y` are layout space; `clientPosition` is in CSS pixels relative to the top-left
corner of the container.

## Type Declaration

| Name | Type | Description |
| ------ | ------ | ------ |
| `clientPosition` | [`Point`](../interfaces/Point.md) | Screen position in CSS pixels, relative to the top-left corner of the container. |

## Remarks

`clientPosition = ((x, y) - pan) * zoom / devicePixelRatio + containerSize / 2`,
with `pan` from [NVL.getPan](../classes/NVL.md#getpan) and `zoom` from [NVL.getScale](../classes/NVL.md#getscale).
