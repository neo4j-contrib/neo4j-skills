# Type Alias: ZoomOptions

```ts
type ZoomOptions = {
  animated?: boolean;
  maxZoom?: number;
  minZoom?: number;
  noPan?: boolean;
  outOnly?: boolean;
};
```

Options that influence how fit-to-zoom should behave

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| `animated?` | `boolean` | If true, will not animate the zoom/pan transition. |
| `maxZoom?` | `number` | The maximum zoom value for the fit-to-zoom operation. This can only lower the [NvlOptions.maxZoom](../interfaces/NvlOptions.md#maxzoom) limit, not raise it. |
| `minZoom?` | `number` | The minimum zoom value for the fit-to-zoom operation. The fit never zooms out further than this. If [NvlOptions.allowDynamicMinZoom](../interfaces/NvlOptions.md#allowdynamicminzoom) is `true`, it can be lower than [NvlOptions.minZoom](../interfaces/NvlOptions.md#minzoom), which is then lowered to the resulting zoom level. If it is `false`, this can only raise the [NvlOptions.minZoom](../interfaces/NvlOptions.md#minzoom) limit, not lower it. |
| `noPan?` | `boolean` | If true, will zoom out to fit the specified nodes without changing the pan of the viewport. |
| `outOnly?` | `boolean` | If true, will only zoom out if specified nodes won't fit into viewport but won't zoom in any further. |
