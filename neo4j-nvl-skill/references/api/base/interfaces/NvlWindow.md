# Interface: NvlWindow

Read-only debugging hooks that every NVL instance registers on `window`, for tests and tooling
that cannot reach the NVL object. Hooks exist from the first instance's construction and stay on
`window` after it is destroyed. `instanceId` is the [NvlOptions.instanceId](NvlOptions.md#instanceid) given to NVL
(default `'default'`); an unknown id falls back to the most recently created instance.
