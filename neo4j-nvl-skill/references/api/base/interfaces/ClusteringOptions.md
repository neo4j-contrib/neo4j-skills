# Interface: ClusteringOptions

Options that control physical clustering and cluster decorations for the force-directed layout.

## Remarks

Only used by the `'forceDirected'` layout. The hierarchical layout has its own
[HierarchicalOptions.clusterBy](HierarchicalOptions.md#clusterby) without decorations.
Clusters can be clicked and hit-tested (see [NVL.getHits](../classes/NVL.md#gethits)), but are not hoverable elements.

## Example

```ts
import { NVL } from '@neo4j-nvl/base'

const nvl = new NVL(document.getElementById('frame'), [{ id: 'a:1' }, { id: 'a:2' }], [])

const clusterBy = (nodeId: string) => nodeId.split(':')[0]
nvl.setLayoutOptions({ clustering: { clusterBy, drawOutline: true } })
```

## Properties

| Property | Type | Default value | Description |
| ------ | ------ | ------ | ------ |
| `clusterBy?` | [`ClusterByFn`](../type-aliases/ClusterByFn.md) | `undefined` | Optional function to group nodes into physical clusters based on a custom identifier. Nodes returning the same string or number will be grouped together in the layout. Nodes returning undefined will be treated as independent. **Remarks** Ensure this function has a stable reference to avoid evaluation on every render. |
| `crossClusterRelationshipMultiplier?` | `number` | `0 @experimental` | **`Experimental`** Spring force multiplier for relationships that cross a [ClusteringOptions.clusterBy](#clusterby) cluster boundary. Capped between `0` and `1`. `0` disables cross-cluster spring pull. `1` is full strength. Intra-cluster edges are always full strength. Only applies when [ClusteringOptions.clusterBy](#clusterby) is set. **Remarks** Can cause unstable layouts when set to close to `1` in highly connected graphs. |
| `drawHalo?` | `boolean` | `false` | Fills a soft glowing halo around each cluster. **Remarks** Halo color is the same as the nodes in the cluster. If the nodes in the cluster have different colors, the halo won't be shown. |
| `drawOutline?` | `boolean` | `false` | Draws a convex-hull outline around each cluster. **Remarks** Outline color is the same as the nodes in the cluster. If the nodes in the cluster have different colors, the outline uses `NvlOptions.styling.overlayLineColor`. |
