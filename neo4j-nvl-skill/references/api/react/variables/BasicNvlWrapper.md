A basic React wrapper that wraps the NVL base library within a React component.
It takes the class' arguments as properties, which are passed to the NVL constructor.

The `ref` exposes every NVL method. Calls made before the instance exists return `null`.

For examples, head to the [Basic React wrapper documentation page](https://neo4j.com/docs/nvl/current/react-wrappers/#_basic_react_wrapper).

## Example

```tsx
const Graph = () => {
  const nvlRef = useRef<NVL>(null)
  return (
    <>
      <BasicNvlWrapper ref={nvlRef} nodes={nodes} rels={relationships} />
      <button onClick={() => nvlRef.current?.fit(nodes.map((node) => node.id))}>Fit</button>
    </>
  )
}
```
