# Variable: InteractiveNvlWrapper

```ts
const InteractiveNvlWrapper: MemoExoticComponent<ForwardRefExoticComponent<Omit<InteractiveNvlWrapperProps & HTMLProps<HTMLDivElement>, "ref"> & RefAttributes<NVL>>>;
```

The interactive React wrapper component contains a collection of interaction handlers by default
and provides a variety of common functionality and callbacks.
It is an extension of the [BasicNvlWrapper](BasicNvlWrapper.md) component and incorporates the
@neo4j-nvl/interaction-handlers module's decorators to provide a set of interaction events.

The mouseEventCallbacks property takes an object where various callbacks can be defined
and behavior can be toggled on and off.
See [MouseEventCallbacks](../type-aliases/MouseEventCallbacks.md) for which key enables which handler.

For examples, head to the [Interactive React wrapper documentation page](https://neo4j.com/docs/nvl/current/react-wrappers/#_interactive_react_wrapper).
