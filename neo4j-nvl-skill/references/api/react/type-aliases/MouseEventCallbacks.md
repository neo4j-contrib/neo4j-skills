# Type Alias: MouseEventCallbacks

```ts
type MouseEventCallbacks = ClickInteractionCallbacks & DragNodeInteractionCallbacks & HoverInteractionCallbacks & PanInteractionCallbacks & ZoomInteractionCallbacks & BoxSelectInteractionCallbacks & DrawInteractionCallbacks & LassoInteractionCallbacks;
```

Collection of mouse event callbacks that can be used with
the [InteractiveNvlWrapper](../variables/InteractiveNvlWrapper.md) component.

Each key enables the interaction handler that owns it: a function enables the handler and is
called.
`true` enables it without a callback and `false` destroys the handler (and all its other callbacks).

## Remarks

Zoom is only enabled through `onZoomAndPan`. There is no `onZoom` key.
Keyboard callbacks use the separate [KeyboardEventCallbacks](KeyboardEventCallbacks.md) prop.
