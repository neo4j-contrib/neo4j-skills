# Type Alias: PanInteractionOptions

```ts
type PanInteractionOptions = {

```

Options for the pan interaction handler to customize its behavior.

## Properties

| Property | Type | Default value | Description |
| ------ | ------ | ------ | ------ |
| `controlledPan?` | `boolean` | `false` | If true, the interaction handler will not update the NVL instance directly. Instead, it will only call the onPan callback with the calculated values, allowing the parent application to control when and how to apply the pan update. |
| `excludeNodeMargin?` | `boolean` | `false` | Whether to not pan when dragging within a certain margin of a node |
