Options for the keyboard interaction handler.
Allows configuring which keys trigger specific navigation actions.
Each key combo is an array of strings: the last element is the primary key (`event.key`),
and any preceding elements are modifier keys (`'Shift'`, `'Ctrl'`, `'Alt'`, `'Meta'`).

## Example

```ts
import { KeyboardInteractionOptions } from '@neo4j-nvl/interaction-handlers'

const options: KeyboardInteractionOptions = {
  navigateForwardKey: ['Tab'],
  contextMenuKey: ['Shift', 'F10']
}
```

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| `canvasOutlineColor?` | `string` | The color of the outline shown when the canvas receives keyboard focus. Default: `'#30839D'` |
| `contextMenuKey?` | `string`[] | Key combo for opening the context menu on the focused element. Default: `['Shift', 'F10']` |

| `largeMoveStepModifier?` | `"Shift"` \| `"Ctrl"` \| `"Alt"` \| `"Meta"` | Modifier key that, held together with a move key, applies [KeyboardInteractionOptions.largeMoveStep](#largemovestep) instead of [KeyboardInteractionOptions.moveStep](#movestep). Default: `'Shift'` |
| `moveDownKey?` | `string`[] | Key combo for moving the selected (or focused) node(s) down. Default: `['ArrowDown']` |

| `moveStep?` | `number` | Distance in screen pixels the node(s) are moved per key press. Converted to graph coordinates using the current zoom level, so the node travels the same visible distance however far the graph is zoomed in or out. Default: `5` |

| `navigateBackwardKey?` | `string`[] | Key combo for navigating focus to the previous element. Default: `['Shift', 'Tab']` |
| `navigateForwardKey?` | `string`[] | Key combo for navigating focus to the next element. Default: `['Tab']` |
