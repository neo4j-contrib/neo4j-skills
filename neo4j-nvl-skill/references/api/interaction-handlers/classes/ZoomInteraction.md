# Class: ZoomInteraction

Interaction handler for zooming the canvas, which is achieved by:
- Scrolling the mouse wheel on the canvas
- Using trackpad pinch gestures (equivalent to Ctrl/Cmd + scroll)

## Remarks

[ZoomInteractionCallbacks.onZoomAndPan](../type-aliases/ZoomInteractionCallbacks.md#onzoomandpan) is the only callback. Zooming also changes the pan so the
point under the pointer stays fixed. Zoom limits come from NVL.getZoomLimits.

For examples, head to the [Zoom Interaction documentation page](https://neo4j.com/docs/nvl/current/interaction-handlers/#_zoominteraction).
