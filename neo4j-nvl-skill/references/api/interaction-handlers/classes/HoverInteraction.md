# Class: HoverInteraction

Interaction handler for hovering nodes and relationships.

## Remarks

Clusters are not hoverable elements: `element` is never a cluster and no hover state is drawn
for hulls. Read `hitElements.clusters` in [HoverInteractionCallbacks.onHover](../type-aliases/HoverInteractionCallbacks.md#onhover), or call
NVL.getHits with `['cluster']`, to react to the pointer being inside a cluster hull.

For examples, head to the [Hover Interaction documentation page](https://neo4j.com/docs/nvl/current/interaction-handlers/#_hoverinteraction).
